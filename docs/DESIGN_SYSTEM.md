# BetterDaily design system

## Principles
Friendly, calm and playful. Gamification encourages action, not guilt. No leaderboards, shame, forced streaks or medical scores.

## Tokens
Forest #215C43 (brand), leaf #49876A (growth), cream #F7F7EF (background), gold #E9C46A (reward accents), sage #DFEBDD (surface), ink #20332B (text). Dark background #17231D, dark surface #22342A, light text #F0F5EC. Gold is decorative, not light-background text.

System sans-serif; body 16px, titles 28–32px. Cards 20px radius; 44px minimum interactive height. Visible keyboard focus, contrast target WCAG 2.2 AA, reduced-motion support. Do not rely on color alone. Use original sprout mark and Lucide outline icons.

## Navigation
Today / Goals / Journal / Progress, with Settings in the header. Mobile bottom navigation; bounded responsive content on desktop. Morning, daytime, evening sections. Empty states explain what is coming without false progress. Faith mode only when enabled. Settings changes show actual save state.
